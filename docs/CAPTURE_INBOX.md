# Capture Inbox

The inbox contains unreviewed CaptureItems, not a second task list. Newest items and `REVIEW_REQUIRED` items are surfaced first. Image, screenshot, and PDF captures expose **Finansta incele**: financial review is a deliberate handoff to `/finance/review/:captureId`, not a direct Finance write. Each item can be reviewed, confirmed, rejected or archived while preserving its source status and source document.
