# Third-Party Architecture References

These are references for patterns, not code sources: Super Productivity, Taskwarrior, Actual Budget, Money Lover, Firefly III, Money Manager Ex, ActivityWatch, Tauri, Tasks.org, Amazing Marvin, Sunsama, Motion, Reclaim, Todoist, Ghostfolio, and Portfolio Performance.

Use them selectively for concepts such as canonical task identity, query-based views, local-first recovery, deterministic reminders, ledger integrity, and explicit review workflows. Do not blindly fork or copy implementation code. Check the license of every source before adapting it.
