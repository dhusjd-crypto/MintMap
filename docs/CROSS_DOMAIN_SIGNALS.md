# Cross-Domain Signals

Command Center presents source-owned signals with a common presentation
severity: INFO, ATTENTION, HIGH and CRITICAL. It does not compare unrelated
numeric scores or monetary values. Execution signals retain task identity;
Finance signals retain FinanceBook and financial entity identity.

The V2 composition caps the visible list and performs only presentation
deduplication for an obligation already linked to an Execution task. Neither
canonical record is removed or mutated.
