# Finance Capture

Financial capture remains proposal-first. Embedded PDF text is supported with safe size/page limits and deterministic statement-label interpretation. Image OCR is currently an explicitly reported platform limitation, not a hidden cloud fallback.

Financial documents stay in Capture until an application-level `FinanceCaptureProposal` is reviewed. Proposal fields contain independent confidence and source provenance. Confirmation creates a canonical statement; extraction never writes Finance truth.
